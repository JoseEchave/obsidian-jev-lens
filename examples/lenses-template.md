# My Lenses
#
# Template for the Jev Lens plugin.
# Copy this file into your vault, rename it (e.g. "Lenses.md"), and edit the
# lenses below. Then point the plugin's "Lens note path" setting at it.
#
# Format rules the plugin understands:
#   - Each lens is a level-3 heading containing "Lens #<number>: <NAME>"
#   - The first "**Covers:**" line under the heading defines the lens.
#     That text is sent to the model as the lens definition, so make it
#     concrete: what counts as this theme, and what does not.
#
# Lenses are deliberately not goals or tasks. They are themes you want to
# notice your life through. Replace the placeholders with your own.

## Tips

- 3–5 lenses work best. More dilutes the signal.
- Rewrite a "Covers" line whenever the theme sharpens for you; the plugin
  re-reads this file on every evaluation, so changes apply immediately.
- The plugin colors tabs by alignment with ANY lens, in the order the lenses
  appear in this note (first lens = first icon in the status bar).
